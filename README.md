# INFO 450 — Programming for Business Analytics (VCU)

Coursework, notebooks, and projects from **INFO 450: Programming for Business Analytics** at Virginia Commonwealth University.

## About the course

INFO 450 is a 3-credit upper-level course in VCU's Information Systems department (School of Business). It covers using Python for data analytics and data science: manipulating, cleaning, and analyzing large datasets, building data visualizations, and developing statistical models. The goal is to be able to take a raw dataset through to data-driven insights and predictive models.

- Python fundamentals for data work

## Running the notebooks

**Google Colab**

1. Open [Google Colab](https://colab.research.google.com/)
2. Choose *File → Open notebook → GitHub* and paste this repo's URL
3. Run the cells top to bottom

**Locally**

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
pip install -r requirements.txt
jupyter notebook
```
